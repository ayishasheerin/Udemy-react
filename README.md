Udemy Clone – React

This project is a Udemy-inspired website initially built using HTML and CSS. I later converted it into a React application by breaking the UI into reusable components.

Technologies Used

* HTML
* CSS
* JavaScript
* React

Features

* Responsive website layout
* Reusable React components
* Navigation bar and course categories
* Course listings and popular courses sections

Getting Started

1. Clone the repository.
2. Install dependencies:

npm install

3. Start the development server:

npm start

Purpose

This project helped me practice React fundamentals, component-based development, and converting a static website into a React application.
